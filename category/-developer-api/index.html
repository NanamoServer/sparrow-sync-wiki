🤝Data Delegation

If your plugin manages player mana, class progression, or skill settings, you can include that data in Sparrow Sync snapshots for persistence, cross-server loading, and rollback. Your plugin continues to manage live player state; Sparrow Sync captures, stores, and restores it.

🗂️Data File Format

Sparrow Sync encodes each player data type as NBT and stores it in a separate block. An index lets readers locate a type without decoding the other blocks.
