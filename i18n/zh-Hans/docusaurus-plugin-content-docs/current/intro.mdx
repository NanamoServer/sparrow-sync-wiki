## 玩家可以带走哪些数据

背包、末影箱、经验、生命值、饥饿值、药水效果、进度、统计、属性、位置等都可以同步。每种数据类型都能在配置中单独开关。

<div className="sync-intro-highlights">

  </div>
  <div>

  </div>

Sparrow Sync 使用 Redis 协调跨服玩家会话，持久化快照可存储在 MongoDB、MySQL、MariaDB 或 PostgreSQL 中。玩家状态在对应的服务器线程上采集，后续编码与存储异步进行；同一玩家的任务按顺序处理。

## 给管理员准备的工具

快照使用 Sparrow NBT 保存，可选择 Zstd、Deflate 或不压缩。遇到问题时，可以查看本地异常档案，也可以通过快照导入、导出和批量归档命令处理数据。已有 HuskSync 或 InvSync 数据的服务器，可以用命令[迁移现有数据](./migration)。具体用法见[命令文档](./commands)。
