## 什么是 Sparrow Sync

Sparrow Sync 是一款用于**跨服务器同步玩家数据**的 **Paper / Folia 插件**。它通过 **Redis** 协调玩家会话，并将玩家数据保存为持久化快照——玩家在不同服务器之间切换时进度不丢失，管理员也可以随时恢复历史存档。

:::info

Sparrow Sync 在对应的服务器线程上采集玩家状态（完全兼容 Folia），再异步编码并保存快照。同一玩家的任务始终按顺序处理，网络波动也不会导致数据乱序写入。

:::

## 可以同步哪些数据

背包、末影箱、经验、生命值、饥饿值、药水效果、进度、统计、属性、位置等——每种数据类型都可以在配置中单独开关。地图数据也可以在服务器之间共享，同步模式与交互限制均可配置。

## 核心功能

- **🗄️ 多种存储后端**——**MongoDB**、**MySQL** 或 **PostgreSQL** 持久化数据，**Redis** 协调跨服操作
- **📦 快照压缩**——使用 Sparrow NBT 保存玩家数据，支持 Zstd、Deflate 和不压缩三种格式
- **🖥️ 快照管理菜单**——在游戏内浏览快照、查看内容、恢复历史数据、固定记录和导出快照
- **🗺️ 地图同步**——在服务器之间共享地图数据，同步模式与交互限制均可配置
- **🔧 数据恢复工具**——查看本地异常档案，通过快照导入、导出和批量归档命令管理数据
- **🔄 数据迁移**——一条命令即可从 **HuskSync** 或 **InvSync** 迁移现有数据

## 快速开始

在每台参与同步的 Paper 或 Folia 服务器上安装插件，配置共用的 Redis 服务和数据库，并在每台服务器的 `server.yml` 中设置互不相同的 `server-id`。
